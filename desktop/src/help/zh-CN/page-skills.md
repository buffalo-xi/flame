# 「技能」这一页

## 列表页

按状态筛选（全部 / 正常 / 废弃）、搜索名称与描述、「系统」开关、「导入」、「新建技能」。

卡片标签把几件事分开写：版本（`v3` / 「未发布」）、归属（私有 / 共享 N）。「共享 N」是能看见它的智能体数量——全员可见时等于智能体总数，白名单时等于已绑定数量，白名单一个人都没绑时变红。悬停浮出：切回正常、废弃、编辑、导出、删除。

## 内容目录与编辑器

新建时后端生成 `SKILL.md` 骨架，编辑器自动打开它。左边是面包屑式目录（新建文件夹/文件、上传、多选删除、刷新），右边是多标签编辑区。

子目录结构没有限制，常见写法是 `references/` 放文档、`scripts/` 放脚本。任何文件都按纯文本打开，只有 `.md` 有「编辑 / 渲染预览」切换。

## 私有技能

归属某个智能体的技能就是私有的。**归属只在新建时决定，建完不能改**，所以想改归属只能重建。

私有的三个后果：不能单独导出（要导出它所属的智能体）、不能单独上架、没有独立版本号（版本跟着智能体走，头部版本入口变成一行提示）。

## 设置面板三个页签

- **可见性**：全员可见或白名单。白名单里点选即保存。
- **工具依赖**：声明这个技能需要哪些工具。**这里只是声明需求，不产生授权**，勾完要点下方「保存」。
- **属性**：归属（仅新建时可选）、用户可调用、命令分发与目标工具。

三个页签的保存语义不一样：可见性与属性改动即时生效，工具依赖要手动保存。

## 可见 ≠ 会进提示词

白名单只决定「哪些智能体能发现它」。要让它真的出现在某个智能体的提示词里，得去那个智能体的「设置 → 调用授权 → 可使用的技能」里绑定，绑定是点一下就存的。绑定时只写技能名与描述，不写全文。

## 工具依赖 ≠ 工具授权

技能声明了「我需要 exec」，不等于调用它的智能体就拿到了 exec。执行命令的智能体仍然必须被平台开通、并被授予对应工具。

## 版本

和智能体同一套：未发布 / vN / vN · 有改动，抽屉里「发布当前草稿」「切到线上」「载入草稿」。废弃期间一切保存被拦，四条版本动作也全部禁用。
