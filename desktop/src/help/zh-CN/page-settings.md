# 「设置」这一页

左侧是分区导航，顶部搜索框能直接跳到某个配置项并高亮。

## 十一个分区

LLM 配置、MCP 连接（出站）、RPC 连接（出站）、MCP 鉴权（入站）、RPC 鉴权（入站）、服务凭证、用户管理、全局变量、租户配额、工作流运行参数、智能体运行参数。

「出站」是我们连出去用别人的服务，「入站」是别人调我们时的鉴权方式——两个方向，别混。

## 全局变量

**这里的「全局」指本租户内全局，不跨租户。** 类型有 text / secret / number / bool。

secret 只在运行期读取、接口不回显，不要写进 `AGENT.md` / `SKILL.md`；编辑 secret 时**留空 = 不修改原值**。资产包只带变量名，不带值。

## 服务凭证

租户级，MCP 与 RPC 共用一份凭证。这里是创建 API Key 的唯一入口。

新建的绑定默认「已限制端点范围且目标为空」——不点「配置」勾上目标，这把 Key **调不到任何端点**。给外部凭证授权超级智能体端点，等于把租户管理能力交出去，别顺手全选。

## LLM 配置

租户级：服务商、模型、接入地址、API Key、上下文与生成参数。可以从「预设服务商」一键带出名称、协议与地址，但**API Key 仍要自己填**，保存前会校验。

## 入站连接

MCP 鉴权 / RPC 鉴权两页只管开关（API Key 或 OAuth），Key 与用户的绑定统一在「服务凭证」里做。

## 账号项不在这一页

修改密码、切换语言、退出都在顶栏。设置页里的「重置密码」是管理员给**其他用户**重置，不是改自己。

## 两个密钥框语义相反

全局变量的 secret 留空 = 不改；LLM 的 API Key 必填、留空会拦。两个框长得一样，行为不一样。
