# 「远端市场」这一页

左边是**我配的对端**（我要去拉的站点），右边是选中站点的资产目录（逐条导入）。

「允许谁来拉我们」不在这页，在「本地市场 → 对外接入」。

## 对端的五个字段

| 字段 | 注意 |
|---|---|
| 站点名 | 唯一，会作为资产来源标记 |
| 地址 | 只填到主机名和端口，路径由系统拼 |
| 认证方式 | 市场令牌（对方要求）/ 公开（不带令牌） |
| 市场令牌 | `flmt_…`；编辑时**留空 = 不修改** |
| 导入策略 | 从该站导入后自动通过（跳过本机审核） |

外加一个「启用该对端」开关。地址里带路径是最常见的配置错误。

## 拉取目录

选中对端就会自动拉一次。目录里**只包含对方已通过审核的资产**；失败不会弹框打断，而是把错误写进该对端的「上次错误」，卡片上直接显示。

## 导入 与 覆盖导入

已导入过的条目显示 `已导入 v{x} → v{y}`，再点就是**覆盖导入**（会二次确认）：本地版本 +1，且如果没开「自动通过」，会**回到待审核**。

导入结果会明确告诉你是哪一种：`已导入并通过（该对端自动通过）` 或 `已导入，等待本机审核`。

## 拉不到怎么办

按卡片上的提示逐条排：`· 未配置令牌`（认证方式选了令牌但没填）、`· 已停用`（关着的对端不会拉）、认证方式选错（对方是公开却填了令牌，或反过来）、地址带了路径。

## 谁能拉我们

在「本地市场 → 对外接入」里配：匿名访问、出口令牌、生成令牌。不在这页。

## 两个「免审」不是一回事

- **上架免审**：租户上架到我们本地市场要不要审（本地市场 → 上架策略）。
- **对端自动通过**：从某个对端拉取导入要不要审（远端市场 → 该对端的导入策略）。

两者互不影响，改一个不会动另一个。
