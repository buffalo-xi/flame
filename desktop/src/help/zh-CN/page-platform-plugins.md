# 「插件与能力」这一页怎么用

左栏是清单，右栏是选中项的设置。插件和能力共用这一页，但两边的缺省方向相反。

## 左栏两组

- **插件（N）**：磁盘上发现的插件，每个都有若干实现。
- **能力（N）**：平台能授权的工具形态（执行 / 常驻会话 / 代码片段 / 浏览器 / 出网）。

条目下面那行小字是统计：「已停用 2/5 家」指有几家租户被单独停用，「已开通 3/5 家」指有几家开了这项能力。

## 右栏两块开关，作用范围完全不同

**全局闸**（顶部）：缺省放行，一旦拉下就是急停 —— 所有租户立即失效，并且**压过**表格里各家的设置。它不修改各家的记录，解除后按原设置恢复。

**表格里每一行**：只影响这一家租户。

## 改完要点该行的「保存」

开关只是草稿。插件的表格里，每一行改完要点那一行的「保存」才提交；顶部的全局闸也有自己的保存按钮。**切到别的插件，或者点右上角「刷新」，未保存的改动会直接丢掉。**

## 三个标签各是什么意思

| 标签 | 位置 | 含义 |
|---|---|---|
| 已停用 | 插件行 | 平台对这家写了停用（`allowed=false`） |
| 显式允许 | 插件行 | 这家存了一条「允许」，效果与缺省相同，属于历史遗留，可以「清除设置」删掉 |
| 缺省开放 | 插件行 | 这家没有单独设置，走缺省（允许） |
| 单独设置 / 未开通 | 能力行 | 有自己的一条记录 / 从来没开通过（缺省拒绝） |

## 什么时候该用急停

发现某个插件或能力有安全问题，需要「立刻让所有租户都用不了」时才拉全局闸。如果只想让某一家停，改表格里那一行，别动全局闸——它影响的是全部租户。

被全局闸拦下时，表格里的行**仍然可以改**：原始设置和急停是两件事，先配好、解除拦截后立即按配置生效。
