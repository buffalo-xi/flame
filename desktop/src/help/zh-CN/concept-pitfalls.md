# 常见误判

这些是把两个相近的动作当成一件事之后最容易出的错。每一条都按「看起来像什么 → 实际是什么」写。

## 「清除设置」在两组上方向相反

- **插件**：清除 = 删掉这家的停用记录 → 回到缺省（允许）→ **放开**。
- **能力**：清除 = 删掉这家的授权记录 → 回到缺省（拒绝）→ **关掉**。

同一个动作，两种结果。按之前先看那行写的是「恢复缺省（允许）」还是「恢复未开通」。

## 停用租户 ≠ 删除租户

停用只是拒绝登录与调用，数据全在，随时可以启用回来。删除会清空该租户的 schema 与文件目录，**不可恢复**，而且正常状态的租户必须先停用才能删。

## 下架 ≠ 卸载

下架是撤出市场：别人装不到新的，**已经装好的副本不受影响**、照常运行。要停掉别人的运行，去停对应租户或对应插件，不要指望下架。

## 收回对外 ≠ 删除端点

收回对外只是停止外部凭证调用，端点记录、入参定义、绑定都还在，再对外开放就恢复。删除才会清记录；对外开放中的端点必须先收回才能删。

## 「载入草稿」不改线上，「切到线上」不改草稿

- **切到线上**：线上立刻按这一版执行，草稿保持原样。
- **载入草稿**：把这一版的内容写回草稿给你继续改，线上仍然跑当前版本，直到你再次发布。

想让改动真正对外生效，必须发布。

## 停用 / 拦截 不是同一个词

插件用「停用 / 解除停用」，能力用「拦截 / 解除拦截」。不是文风问题：两个域的数据表和默认方向都不同，混着叫会让人以为改一个就动了另一个。

## 看到「未设置」先确认缺省方向

「未设置」不等于「关着」：

- 插件未设置 = 允许（租户自己启用就能用）
- 能力未设置 = 未开通（拒绝）

判断某个东西能不能用，要看**生效**那一列，不要看是否「未设置」。

## 可见 ≠ 会进提示词

技能设成「全员可见」或加进白名单，只是让它能被智能体**发现**。要真正写进某个智能体的提示词，得在那个智能体的「调用授权 → 可使用的技能」里绑定；绑定时只写技能名与描述。

## 技能声明工具 ≠ 授权工具

技能里勾了「我需要 exec」只是声明需求。执行命令的智能体仍然必须被平台开通能力、并被授予对应工具，否则调用时照样被拒。

## 配额超顶，两边行为不同

管理员填高于系统顶的值：照存，但按系统顶截断生效（卡底有黄字提示）。租户自己填超顶：**直接拒绝**，保存不了。
