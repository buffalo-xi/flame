# 「平台用户」这一页

## 列表与筛选

左边卡片列表、右边详情。卡片三行：显示名 + 角色标签、账号（「我」/「根账号」标记）、状态 + 名下租户数。可按账号或显示名搜索（回车触发）、按角色、按状态筛选，底部是后端分页。

## 新建用户

字段：账号（字母/数字/下划线/横线，1-64 位）、显示名（可留空，留空显示账号名）、角色（默认「用户」）、初始密码（预填 `12345678`，可改）。账号与初始密码必填。

## 两个角色

- **管理员**：管所有租户，详情里不显示「名下租户」。
- **用户**：只管自己名下租户。

改角色前会二次确认，因为权限立刻变化。

## 账号状态只有三种

正常 / 已停用 / 已锁定。**「待完成」「已删除」不是账号状态**，它们只出现在「名下租户」那一列里，是租户的状态。

「锁定」与「停用」对登录的拦截完全一样（都拒登），只是标签不同；卡头的「启用」会把两者都直接拉回「正常」。

## 四条保护规则

- 不能停用当前登录账号（按钮直接禁用）。
- 根账号只读：不可改、不可停用、不可删除。
- 不能停用或降级最后一个「正常」的管理员——这条前端没有按钮拦截，是后端拒。
- 停用或降级后，其名下租户**不会自动转让**，需要事后到「租户管理」里改负责人。

## 重置密码不会踢人下线

重置只作用于这一个账号，要求至少 8 位、两次一致。**已经签发的 token 不会失效**，那个人在别的窗口里照样能用；要立刻踢下线，先把账号停用（或锁定）再启用。
