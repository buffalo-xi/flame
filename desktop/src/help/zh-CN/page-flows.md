# 「工作流」这一页与编辑器

## 列表页

顶部按状态筛选（全部 / 正常 / 废弃）、搜索名称与描述，右边「导入」和「新增工作流」。卡片上显示名称、状态、版本（`v3` 或「未发布」）、协议（mcp / rpc 或「未设置端点」）、最后更新人。

鼠标悬停浮出五个动作：切回正常、废弃、端点、导出为资产包、删除。**废弃会同时收回该工作流全部端点的对外**，部署里还在调的调用方会立刻失败。

## 编辑器分成三块

左侧竖向工具条（加节点、加注释、变量面板入口）、中间画布、右侧浮层面板（节点属性、变量、运行）。面板可以拖宽，也可以关掉。

**加节点有两条路**：工具条「+」→ 选类型 → 再点画布落位；或者点已有节点上的「+」→ 选类型，新节点自动建在右边并连线。注释不占节点名额。

## 连线的硬规矩

source / target handle 不能同类型互连，不能自连、不能成环、不能跨父容器；而且**一个出口只保留一条出边、一个入口只保留一条入边** —— 重连是覆盖，不是新增。

## 变量的三类来源

| 来源 | 谁维护 | 说明 |
|---|---|---|
| 流程变量 | 本工作流 | 编辑器里可读写 |
| 环境变量 | 本工作流 | 随工作流走 |
| 全局变量 | 租户级，编辑器里**只读** | 维护在「设置 → 全局变量」；地址、账号、密钥建议放这里 |

在节点的「输入变量」里引用前，要先把来源选对，模板（`{{.input.x}}` / `{{.local.x}}` / `{{.output.x}}`）才认。

## 试运行

点「运行」会**先自动保存**再跑。结果看三处：右侧运行面板（本次运行 / 历史运行）、变量面板的「执行结果」子页、画布上节点的调试高亮（执行中 / 已运行 / 跳过 / 出错 / 断点）。

## 保存 ≠ 发布 ≠ 生效

- **保存**：只写草稿。
- **发布当前内容**：冻结当前已保存内容为新版本，正式调用立刻跑这一版；有未保存改动会被拦。
- **切到线上**：只换「线上跑哪一版」，画布草稿一动不动。
- **载入画布**：把该版本写回草稿，线上仍是原来那版，要再发布才生效。想丢掉草稿回到线上那份，也用它。

头部版本按钮有三种状态：「未发布」（还没发布过，线上不可调用）、「v3 · 有改动」（线上是 v3，草稿比它新）、「v3」。

## 端点

编辑器头部「端点」按钮就地管理这个工作流的入口，不用跳去端点页。工作流没保存前点它会提示先保存。端点参数不能手写，恒等于开始节点声明的入参；RPC 端点由流程托管，不能单独删。

**有对外端点时保存会二次确认**：改名会连带改变对外工具名（`local__<name>`），外部接入方要同步改。
