# 「我的租户」这一页

这是**租户负责人**的视角：只列出你名下（你是负责人）的租户，别人的看不到。列表按本地过滤，不分页；所有卡片默认是收起的，点标题展开。

## 能自助的

- **停用 / 启用本租户**：停用后该租户无法登录控制台，MCP / RPC 调用也会被拒，立即生效。
- **五项配额**：智能体、技能、工作流、单会话空间、单用户会话数。受系统顶约束。
- **工作流运行参数、智能体运行参数**：留空回退系统级，`-1` 表示不限制。智能体那一组没有 `-1`——它们都是安全阀，调成「不限制」等于拆掉防线。
- **重置根账号 primary 的密码**。

## 必须找平台管理员的

- 转移租户归属（改负责人）
- 改系统顶本身
- 插件停用策略、能力授权
- 新建或删除租户

页脚那句「调整配额上限、转移归属请找平台管理员」指的就是这些：配额能改，但天花板改不了。

## 重置根账号密码

只重置本租户根账号 `primary`，不动它的角色和状态。要求至少 8 位、两次一致。

**已登录的会话不会失效**——重置后旧密码作废，但已经在里面的人出不来。要立刻踢下线，停用本租户。

## 配额改超了会被直接拒

和管理员那一侧不同：管理员填高于系统顶的值会被截断生效（带黄字提示），租户自己填超顶是**直接拒绝**并提示「不能超过系统级值」。

填之前先看那一行的「系统顶」列，留空就是回退到它。

## 备注是管理员写的

右侧「租户信息」里的备注由平台管理员填写，你能看到原文。想改备注、改显示名，都只能找管理员。
