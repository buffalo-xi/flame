# 「智能体」这一页

## 列表页

顶部按状态筛选（全部 / 正常 / 废弃，带计数）、搜索名称与描述，右边「导入」和「新增智能体」。还有个「系统」开关，只控制要不要显示内置的受保护智能体（比如 main），不改任何数据。

卡片上显示名称、状态、版本（`v3` / 「未发布」）、端点协议标签、描述、最后更新人。悬停浮出五个动作：切回正常、废弃、端点、导出为资产包、删除。**删除要求线上没有发布版本**：v3 还在跑时会被拦下，提示先在版本面板「取消发布」；废弃态可以直接删（废弃本身就是停服那一步）。

## 编辑区就是一个档案目录

点卡片直接进全屏编辑，左边是目录树，右边是多标签文本编辑器。根上的 `AGENT.md` 是智能体的主定义，进入时自动打开，**可以编辑但不能删除**；`skills/` 目录只读，由技能页维护。

## 设置面板两个 tab

右上「设置」打开右侧抽屉：

- **调用授权**：可使用的技能、是否允许发现未绑定的技能、默认回复语言、超级权限，以及「谁能调用它 / 它可以调用谁」两个方向。
- **工具配置**：不限制工具开关、添加工具与工具组、授权三区。

## 工具授权分三区

「必须导入 / 可使用 / 拒绝」。点「添加工具 / 组」从左侧滑出侧栏，先选落在哪个区，再点组卡或单个工具。

**三区改完要回到配置面板点「保存」才生效**，不会即时落库。

## 顶部「保存」只存当前文件

这是最容易踩的一条：头部那个保存按钮只写当前打开的文件。设置面板里的东西各走各的——工具授权要点面板内的「保存」，技能绑定和那两个开关是点一下就存。

## 版本

头部版本徽标有三种（未发布 / v3 / v3 · 有改动），点开是版本抽屉：「发布当前草稿」「切到线上」「载入草稿」。发布不影响草稿，切到线上只换线上指针，载入草稿只写回草稿。四个动作的完整对照见帮助中心的「保存、发布、切到线上、载入草稿」。

## 端点

智能体也能对外暴露。入口是列表卡片悬停时的「端点」图标，打开右侧抽屉：协议只有 MCP / RPC 且同一种只能建一个，端点名就是实体名不可改，智能体不声明入参、外部按自由 JSON 传。对外开放中的端点不能删除；「废弃」会自动收回它全部的对外。没发布过正式版本时不能对外开放，先发布再开；超级智能体例外，它始终按草稿运行。

## 三个东西别搞混

- **「系统」开关**：只是显示/隐藏，不改数据。
- **「废弃」**：整个智能体只读，能一键切回正常。
- **紫色盾牌**：表示超级权限，不是「系统内置」。
