# 保存、发布、切到线上、载入草稿、取消发布

智能体、技能、自定义工具、工作流都有版本。五个动作长得很像，作用范围完全不同。

## 五个动作各做什么

| 动作 | 碰草稿 | 碰线上 | 什么时候用 |
|---|---|---|---|
| 保存 | 写 | 不动 | 日常编辑，随时可以存 |
| 发布 | 读（必须是已保存的内容） | 换到新版本 | 想让正式调用用上新内容 |
| 切到线上 | **不动** | 换到旧版本 | 上线后发现不对，立刻退回 |
| 载入草稿（工作流里叫「载入画布」） | 覆盖 | **不动** | 拿旧版本当起点重做，或丢掉草稿回到线上那份 |
| 取消发布 | 不动 | **摘掉当前版本**（历史、端点、授权都不动） | 想先下线，或要删除整个实体 |

## 有发布版本时不能直接删

删除实体（智能体 / 技能 / 自定义工具 / 工作流）之前，线上必须没有发布版本：有 v3 在跑时删除会被拦下，提示先「取消发布」。取消发布只摘掉线上指针，草稿和历史都还在，之后想发还能再发；删除之后历史版本才随实体一起清空。废弃不拦删除 —— 废弃本身已经是停服那一步。

## 草稿和线上是两份东西

草稿是你正在改的那份，线上是正式调用（MCP / RPC / 端点 / 别的流程）真正执行的那份。

所以「保存了」不等于「生效了」：保存只写草稿，线上还在跑上一个版本；要等发布。

## 头部三种状态

- **未发布**：还没发布过，线上不可调用。
- **v3 · 有改动**：线上是 v3，草稿比它新 —— 现在调用的还是 v3。
- **v3**：草稿和线上一致。

列表页上那个「未发布」标签是同一件事：它没有可被外部调用的正式版本。

## 授权和绑定不随版本走

版本只搬「定义」。**谁能调用它**（授权、技能绑定）始终是当前配置，回退版本不会把它们一起退回去 —— 回退后仍然是回退前那一套。

例外：智能体上「不限制工具 / 技能发现」这两个开关属于定义，载入草稿时会被那一版写回。

## 为什么「载入草稿」不是回滚

回滚要的是「线上立刻变」，那是**切到线上**。载入草稿只改你手上的工作副本，线上一点没变 —— 用它回滚会以为生效了，其实没有。
