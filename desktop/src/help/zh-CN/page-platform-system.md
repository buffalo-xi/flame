# 「系统设置」这一页

左边是域导航，右边四张可折叠卡：配额上限、工作流运行参数、智能体运行参数、LLM 服务商预设。每张卡自己加载、自己校验、自己保存。

## 配额上限

五项：智能体、技能、工作流、单会话空间（MiB）、单用户会话数。表格三列分别是配置项、兜底值、系统级设置——你能改的只有第三列。

## 运行参数

工作流七项（最大超时、递归深度、节点数、执行次数、循环次数、运行记录数、会话记忆），智能体六项。每项都带一句说明，`-1` 表示不限制。

## 留空、-1、0 是三件事

- **留空** = 未设置，回落到「兜底值」。兜底值是代码内置的默认，只读，改不了。
- **-1** = 不限制。
- **0** = 一个都不许新建。

工作流与配额可以填 `-1`；智能体那组是安全阀，不支持 `-1`。会话空间按 MiB 填，后端存字节。

## 系统值是硬顶，不是覆盖

运行期取 **min(租户值, 系统值)**。你把系统值调低，等于给所有租户加了个天花板，而不是把他们的值改成你的值；已有对象不会被删，租户行也不会被改写。

保存前会弹确认，逐项列「旧 → 新」，因为一次可能改了好几项。

## LLM 预设是全局共享的

这里维护的是服务商预设，**所有租户共用**。租户在「设置 → LLM 配置」里点某个预设，只是把名称、协议、地址**复制**进自己的记录，之后各存各的（API Key 也是租户自己的）。

所以删除一个预设，不会影响已经复制过的租户配置。
