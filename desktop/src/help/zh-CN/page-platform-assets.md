# 「本地市场」这一页

平台在这里**只治理、不搬运**：资产快照由租户上架或导入产生，安装也发生在租户侧；这一页只改状态与可见范围。

## 三个二级标签

- **全部资产**：按状态分块的卡片流，角标是**待审条数**，不是总数。
- **上架策略**：租户上架后要不要审。
- **对外接入**：允许哪些外部站点来拉我们的资产（另见「远端市场」）。

## 全部资产按状态分块

待审核 / 已上架 / 已驳回 / 已下架 / 草稿 / 其它。顺序就是处置顺序，待审在最上、草稿沉底；空组不显示，组头可以收起。

状态是单向的：`草稿 → 待审 → 已上架 / 已驳回`，`已上架 → 已下架`。越级的动作后端会拒。

## 卡片上的动作按状态出现

导出包（有文件时）、通过 / 驳回（仅待审核）、下架（仅已上架）、删除（已上架 / 已下架）。待审核、已驳回、草稿的条目**点不到下架和删除**，模板里就不渲染。

## 通过 与 驳回

- **通过**：立刻进入「可见范围」内的租户可安装状态，可以附一条审核意见。
- **驳回**：状态变「已驳回」，**驳回原因必填**，提供方在租户控制台「我的资产」里看到原文，要重新上架（版本 +1）才会重新进队列。

## 上架策略：全局默认 + 按租户覆盖

全局一个开关（上架需审核 / 上架免审，**缺省免审**），下面可以按租户覆盖成「跟随默认 / 必须审核 / 免审」。**只影响之后的上架，不追溯已经上架的条目。**

## 下架 ≠ 删除

- **下架**：留档撤出。立刻从所有租户的市场消失，库里的记录还在，之后仍可删除。
- **删除**：清库。快照、可见范围、安装记录一起清空，**不可恢复**。

两者都**不影响已经装到租户里的副本**。删除不要求先下架。

## 界面上的词

这一页叫「全部资产」「待审核」「上架策略」。代码注释里说的「资产池」「入库审核」不是界面文案，对着人讲的时候用前一套。
